First release of RustKVM: a browser-based KVM-over-IP for RK3588 boards, written in Rust,
with hardware H.264/H.265 encoding and a JSON-RPC / MCP API for automation and AI agents.

## Highlights

- **Remote console** in the browser over WebRTC: hardware-encoded video via Rockchip MPP,
  Opus audio, keyboard and five-button mouse, EDID control, screenshots.
- **Virtual media**: mount an ISO by URL or from device storage, bundled netboot.xyz.
- **Power control**: ATX power / reset and DC power, Wake-on-LAN.
- **Automation**: 130+ JSON-RPC methods over WebRTC or `POST /device/rpc`, an MCP server at
  `POST /mcp`, API tokens, MQTT with Home Assistant discovery, Prometheus `/metrics`,
  `/device/health`.
- **Reliability**: hardware watchdog, self-healing video pipeline.
- **Reproducible builds**: Docker devkit and a pinned firmware build; this release's
  application and firmware were built with them.

## Downloads

| File | What it is |
| --- | --- |
| `rustkvm-rk3588-*-eflasher.img.gz` | Writes RustKVM to the board's eMMC (recommended) |
| `rustkvm-rk3588-*-sd.img.gz` | Runs RustKVM from a microSD card |
| `rustkvm_app-aarch64-unknown-linux-gnu` | The application binary alone, for existing installs |
| `rustkvm-*-source.tar.gz`, `*-legal-info.tar.gz` | Corresponding source and licenses |
| `SHA256SUMS`, `*.SHA256SUMS` and `.asc` | Checksums and their GPG signatures |

Flashing and first boot: [docs/quickstart.md](https://github.com/Rust-KVM/rustkvm/blob/dev/docs/quickstart.md).

Verify a download:

```bash
gpg --import release-signing-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS && sha256sum -c SHA256SUMS --ignore-missing
```

## Known limitations

- Over-the-air updates are not in this release; update by reflashing.
- No factory reset button yet; delete `/userdata/rustkvm/config.toml` to return to the
  setup wizard.
- The TLS certificate is self-signed and regenerated at every start until you install
  your own under Settings → TLS.

Full list of changes: [CHANGELOG.md](https://github.com/Rust-KVM/rustkvm/blob/dev/CHANGELOG.md).
